# ربات رفرال تلگرام (aiogram 3 + Railway)

## امکانات
- منوی اصلی با ۶ دکمه شیشه‌ای: 🎁 کد هدیه | 🏆 چالش | 👤 پروفایل | 👥 رفرال | 💬 پشتیبانی | 🌐 زبان
- لینک رفرال اختصاصی برای هر کاربر (`t.me/YourBot?start=ref_<ID>`)
- جوین اجباری کانال: رفرال فقط وقتی حساب می‌شود که کاربر جدید **عضو کانال** شود
- به ازای هر رفرال موفق، `REF_REWARD` توکن به معرف داده می‌شود و به او پیام می‌رود
- ضدتقلب: کاربر نمی‌تواند خودش را رفرال کند و هر کاربر فقط یک بار حساب می‌شود
- کد هدیه با ظرفیت مشخص؛ هر کاربر هر کد را فقط یک بار می‌تواند استفاده کند
- بخش چالش: لیست چالش‌ها و جوایز، تعداد شرکت‌کنندگان، زمان باقی‌مانده، دکمه «ثبت شرکت» و «🔄 بروزرسانی»
- هر چالش زمان پایان و هزینه شرکت (توکن یا رایگان) دارد؛ ادمین با /draw قرعه‌کشی می‌کند
- پشتیبانی داخل ربات: ادمین با Reply زدن جواب می‌دهد
- دو زبانه (فارسی / انگلیسی)
- پنل ادمین: آمار، برترین‌ها، ارسال همگانی، مدیریت توکن، کد و جایزه

## قبل از دیپلوی
1. در @BotFather ربات بسازید و توکن را بگیرید.
2. آیدی عددی خودتان را از @userinfobot بگیرید.
3. **ربات را ادمین کانال کنید** (بدون این، بررسی عضویت کار نمی‌کند).

## دیپلوی روی Railway
1. این پوشه را در یک ریپوی GitHub آپلود کنید (فایل `.env` را آپلود نکنید).
2. در Railway: **New Project → Deploy from GitHub repo** و ریپو را انتخاب کنید.
3. در تب **Variables** این متغیرها را بگذارید:

| متغیر | مثال | توضیح |
|---|---|---|
| `BOT_TOKEN` | `123456:AA...` | توکن BotFather |
| `ADMIN_IDS` | `111111111,222222222` | آیدی عددی ادمین‌ها |
| `CHANNEL_ID` | `@mychannel` یا `-100123...` | کانال جوین اجباری |
| `CHANNEL_LINK` | `https://t.me/+abc...` | فقط برای کانال خصوصی |
| `REF_REWARD` | `1` | توکن هر رفرال |
| `DEFAULT_LANG` | `fa` | زبان پیش‌فرض |
| `DB_PATH` | `/data/bot.db` | مسیر دیتابیس |
| `DEFAULT_WIN_COOLDOWN` | `24` | پیش‌فرض محدودیت شرکت برندگان اخیر (ساعت) |
| `TIMEZONE` | `Asia/Tehran` | منطقه زمانی نمایش تاریخ پایان چالش |

4. **خیلی مهم:** روی سرویس کلیک راست کنید → **Attach Volume** و Mount path را `/data` بگذارید.
   بدون Volume، با هر دیپلوی دیتابیس (توکن‌ها و رفرال‌ها) پاک می‌شود.
5. Deploy کنید. در Logs باید `Bot started as @YourBot` را ببینید.
6. تعداد Replicas باید **۱** باشد (اجرای هم‌زمان دو نسخه خطای Conflict می‌دهد).

## دستورات ادمین
در ربات `/admin` را بزنید تا راهنما بیاید:
- `/stats` آمار · `/top` برترین‌ها · `/user ID` اطلاعات کاربر
- `/addtokens ID AMOUNT` افزودن/کسر توکن
- `/addcode CODE AMOUNT MAX_USES` ساخت کد هدیه (0 = نامحدود) · `/delcode CODE` · `/codes`
- **چالش‌ها** (راهنمای کامل با `/admin`):
  - `/addch مدت [تنظیمات] عنوان | جایزه | توضیحات`
    مثال: `/addch 2d winners=3 cost=5 limit=100 cooldown=24 refs=2 چالش ویژه | ۳ پریمیوم | توضیح`
    تنظیمات اختیاری: `winners` تعداد برنده · `cost` هزینه توکن · `limit` ظرفیت · `cooldown` محدودیت برندگان اخیر (ساعت) · `refs` حداقل رفرال
  - `/setch ID تنظیمات` · `/settime ID مدت` · `/chs` · `/parts ID`
  - `/draw ID` قرعه‌کشی فوری · `/cancelch ID دلیل` لغو + اعلان به همه + برگشت هزینه · `/delch ID` حذف بی‌صدا
  - قرعه‌کشی در پایان زمان هر چالش **خودکار** انجام می‌شود و نتیجه (برنده/بازنده) برای همه شرکت‌کنندگان ارسال می‌شود.
- Reply روی یک پیام + `/broadcast` ارسال همگانی
- Reply روی پیام پشتیبانی = پاسخ به کاربر

## اجرای محلی
```bash
pip install -r requirements.txt
cp .env.example .env   # مقادیر را پر کنید و DB_PATH=data/bot.db بگذارید
python main.py
```

## ساختار فایل‌ها
- `main.py` نقطه شروع
- `config.py` تنظیمات از متغیرهای محیطی
- `database.py` دیتابیس SQLite
- `handlers_user.py` منو و بخش‌های کاربر
- `handlers_admin.py` پنل ادمین و پاسخ پشتیبانی
- `keyboards.py` دکمه‌های شیشه‌ای
- `challenge_service.py` قرعه‌کشی خودکار، لغو و اعلان‌های چالش
- `timeutils.py` محاسبه زمان باقی‌مانده و مدت چالش‌ها
- `texts.py` متن‌های فارسی و انگلیسی (برای تغییر متن‌ها این فایل را ویرایش کنید)
